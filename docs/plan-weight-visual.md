# План: «живая» визуализация веса в экране тренировки

> Задание для исполнителя (Claude Opus). Самодостаточный документ: весь нужный контекст здесь и в указанных файлах. Дизайн утверждён на интерактивных макетах с владельцем проекта — следовать спецификациям ниже, не изобретать своё.

## Контекст и цель

PWA-трекер силовых тренировок (Vite + React 18 + TS, данные в localStorage, тёмная тема, UI на русском). Экран живого логирования — `src/screens/Workout.tsx`: карточка текущего упражнения содержит блок `.logger` со степперами «Вес»/«Повторы» и кнопкой «Записать подход».

Задача: добавить над степпером **отображающую** визуализацию веса. Тип оборудования упражнения задаёт метафору:

| Equipment | Визуал |
|---|---|
| `Штанга` | Гриф, на который с анимацией «надеваются» цветные блины + подпись-калькулятор «на сторону: 25 + 5» |
| `Гантели` | Гантель: головки растут с весом, число написано на головках |
| `Блок`, `Тренажёр` | Весовой стек: зелёный пин скользит к выбранной плите, поднимаемые плиты подсвечены, «магнит-добавка» при дробном остатке |
| `Свой вес` | Насечки мелом по **повторам** (группы по 5: четыре палочки + перечёркивающая диагональ) |

Это чисто визуальная фича: **никаких изменений** модели данных (`src/types.ts`), стораджа (`src/lib/storage.ts`), логики записи подходов и расчётов прогресса (`src/lib/calc.ts`).

## Принципы

- Только рендер: компонент читает `equipment` / `weight` / `reps`, ничего не пишет и не перехватывает ввод (`pointer-events: none` на визуале).
- Ноль новых зависимостей. Анимации — чистый CSS (keyframes + transition).
- Дизайн-токены из `:root` в `src/index.css`: `--green`, `--green-ink`, `--muted`, `--ease` и т.д. «Железо» (гриф, плиты стека, головки гантели) — литеральные цвета, от темы не зависят.
- Стиль кода как в проекте: русские комментарии, компактные функциональные компоненты, короткие CSS-классы. Всем новым классам префикс `wv-`.
- Единицы — кг (переключатель фунтов в настройках сейчас no-op, игнорировать).
- Фиксированные высоты блоков по типам — layout не должен прыгать при изменении веса.
- `@media (prefers-reduced-motion: reduce)` — отключить все `wv-*` анимации и transition.

## Архитектура

**1. `src/lib/plates.ts` (новый)** — чистая математика раскладки:

```ts
export const BAR_KG = 20
export const PLATES = [25, 20, 15, 10, 5, 2.5, 1.25]

/** Жадная раскладка блинов на одну сторону грифа.
 *  remainder — вес, который блинами не набирается (свободный ввод, напр. 77 кг). */
export function platesPerSide(totalKg: number): { plates: number[]; remainder: number }
```

Пример: `platesPerSide(77)` → на сторону 28,5 → `{ plates: [25, 2.5], remainder: 1 }`.

В `src/lib/util.ts` добавить `ruNum(n: number): string` — число с запятой вместо точки (`2.5` → `"2,5"`).

**2. `src/components/WeightVisual.tsx` (новый)** — единственный публичный компонент:

```ts
export default function WeightVisual(props: {
  equipment?: Equipment  // undefined → рендерим null
  weight: number
  reps: number
})
```

Внутри — приватные подкомпоненты `Barbell`, `Dumbbell`, `Stack`, `Tally`; выбор по `equipment` (`Блок` и `Тренажёр` → `Stack`; `Свой вес` → `Tally(reps)`).

**3. CSS** — секция в конце `src/index.css`: `/* ---- WeightVisual: живая визуализация веса ---- */`.

**4. Интеграция** — `src/screens/Workout.tsx`, внутри `<div className="logger">` первой строкой (перед `<div className="stepper">`):

```tsx
<WeightVisual equipment={ex?.equipment} weight={weight} reps={reps} />
```

Стейты `weight`/`reps` уже существуют и уже префиллятся из истории при смене упражнения — трогать их не нужно.

## Спецификация: штанга (`wv-bb`)

Высота блока 104px. Разметка: сторона L · гриф · сторона R. Каждая сторона: рукав-фон (полоса 12px высотой через всю сторону), поверх — ряд блинов (тяжёлые у замка, т.е. у внутреннего края), у внутреннего края замок-упор 6×26px. Гриф — полоса 8px между сторонами.

Размеры блинов `{кг: [высота, ширина]}`: `25:[96,24] 20:[90,22] 15:[78,20] 10:[64,18] 5:[48,14] 2.5:[38,11] 1.25:[28,9]`. Скругление 4px, рамка `1px solid rgba(0,0,0,.4)`, `box-sizing: border-box`.

Цвета (соревновательный стандарт): 25 `#EF4444`, 20 `#3B82F6`, 15 `#EAB308`, 10 `var(--green)`, 5 `#E5E7EB`, 2.5 `#4B5563`, 1.25 `#9CA3AF`. Подпись номинала только на блинах ≥ 10 кг (11px, 700): на красном/синем `rgba(255,255,255,.95)`, на жёлтом `#4A3A05`, на зелёном `var(--green-ink)`, на белом (5 кг) `#22272B`. Металл: рукав и гриф `#565D66`, замок `#6E757D`.

Подпись под штангой (13px, по центру): `на сторону: 25 + 2,5` цветом `var(--green)`; при `remainder > 0` дописать ` · ещё 1 кг не разложить` цветом `var(--muted)`.

Крайние случаи: `weight <= 0` → компонент null; `0 < weight < 20` → пустой гриф + подпись «легче грифа (20 кг)» muted; расчёт клампить сверху 300 кг.

Анимация появления блина: `translateX(±44px) → овершут ∓2px → 0` + opacity, 380ms `cubic-bezier(.22,1,.36,1)`, направление — от конца рукава к замку (для правой стороны из +44, для левой из −44; два keyframes `wv-in-r` / `wv-in-l`). Убранные блины исчезают без анимации.

Определение «новых» блинов: предыдущую раскладку хранить в `useRef`; во время рендера сравнением мультимножеств (счётчик по номиналу: экземпляр новый, если его порядковый номер среди одинаковых номиналов превышает прежнее количество) вычислять флаг `isNew`, в `useEffect` обновлять ref. Ключ элемента — `` `${p}-${i}` ``.

Nice-to-have (если без костылей): «вздрагивание» обёртки при изменении веса — keyframes `translateY(0→3px→−1px→0)` 300ms, перезапуск через `ref.classList.remove/void offsetWidth/add` в `useEffect` по `weight`. Ремаунт по key не использовать — он перезапустит анимации всех блинов.

## Спецификация: гантель (`wv-db`)

Высота блока 110px. Головка: `h = min(104, 40 + weight*1.6)`, `w = min(40, 16 + weight*0.45)`, фон `#4B5563`, рамка `1px solid rgba(0,0,0,.4)`, скругление 8px, `transition: width .25s var(--ease), height .25s var(--ease)`. Рукоять между головками 54×9px, `#6E757D`, скругление 3px. Число веса (`ruNum`) на обеих головках: 11px, 700, `rgba(255,255,255,.9)`; показывать при `weight >= 2`. `weight <= 0` → null. Вес трактуется как вес одной гантели (так и логируется сейчас). Подпись под визуалом не нужна.

## Спецификация: весовой стек (`wv-st`) — Блок и Тренажёр

Высота блока 152px. Стек: 12 плит (номиналы 5…60 кг сверху вниз), каждая 90×10px, скругление 2px, рамка `1px solid rgba(0,0,0,.35)`, зазор 2px. За плитами вертикальный шток 6px (`#565D66`), выступает над стеком на 8px.

`k = floor(min(weight, 60) / 5)`, минимум 1 при `weight > 0`; остаток `r = weight − k*5` (для weight ≤ 60). Плиты с индексом `< k` активные — фон `#7E868E`, остальные `#3A4046`; `transition: background .2s`. Пин: `var(--green)`, 34×6px, скругление 3px, торчит вправо за край плиты на 16px, вертикальная позиция — по центру плиты `k−1`, `transition: top .25s var(--ease)`. «Магнит» при `r > 0`: плашка 40×5px `#9CA3AF` поверх штока над первой плитой. `weight > 60` → пин на нижней плите, магнит скрыт. `weight <= 0` → null.

Все 12 плит рендерить статично (не пересоздавать) — меняются только фон плит и `top` пина, иначе transition пина не сработает.

## Спецификация: насечки (`wv-tl`) — Свой вес

Привязка к `reps` (весовой инпут для своего веса не используется — в проекте уже принята метрика повторов, см. `isRepsBased` в calc.ts). Высота auto (мин. 44px), `flex-wrap`, группы по 14px зазора.

Полная группа (5 повторов): контейнер 30×34px relative; 4 вертикальные палочки 3×30px (зазор 6px, скругление 2px) + диагональ 42×3px absolute (`left:-6px; top:14px`, `rotate(-25deg)`). Цвет «мела» — `#E7E9EB`. Неполная группа — остаток палочек.

Анимации новых элементов (флаги через `prevReps` в `useRef`, по аналогии со штангой): палочка — `scaleY` от 0, `transform-origin: bottom`, 200ms; диагональ — `scaleX` от 0 + rotate, `transform-origin: left center`, 250ms.

Рисовать максимум 30 насечек; свыше — дописать `×N` цветом `var(--muted)`. `reps < 1` → null.

## Ручная проверка (`npm run dev` → localhost:5173)

Seed-данные создаются при первом запуске (`src/lib/seed.ts`). Если в программе нет упражнения нужного типа — временно добавить через редактор программы или каталог.

- Штанга: начать тренировку, упражнение со штангой. Префилл веса из истории → раскладка корректна сразу. `+2,5` → на каждую сторону с анимацией «надевается» один блин 1,25. Ручной ввод `77` → подпись «ещё 1 кг не разложить». Ввод `12` → пустой гриф, «легче грифа». Проверить точность подписи: 80 → «на сторону: 25 + 5».
- Гантели: головки растут плавно, число на головках = значению степпера.
- Блок/Тренажёр: пин скользит, активные плиты светлеют, при 42,5 виден магнит, при 60+ пин на дне без поломок.
- Свой вес (подтягивания): насечки = повторам, каждая пятая перечёркивает группу; вес-визуала нет.
- Общее: быстрый спам ± не ломает анимации и не лагает; ширина вьюпорта 360px без переполнений; системный reduced motion отключает анимации; подходы записываются как раньше; `npm run build` чистый.
